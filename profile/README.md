# Bethel AI Labs

Building context-engineering systems and deep agents that wrap Claude, Codex, and other AIs around knowledge you approve — not guesses.

## What we build

- **Knowlith** — local company brain → evidence gate → human approve → MCP to Claude / Codex / Cursor
- Context-engineering wrappers around the tools teams already use
- Deep-agent pipelines that stay honest: evidence quotes, approve-before-serve, Activity = what was read

## Principles

- Context is the scarce asset
- Evidence quotes, not guesses
- Approve before any assistant sees answers
- Activity shows reads — not why a model answered
